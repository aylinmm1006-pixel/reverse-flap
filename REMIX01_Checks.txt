Explanation for teacher: I changed the original obstacle-dodging mechanic. Instead of tapping to move the character, you move the pipe gap, so you have to predict the automatically moving bird. The arrow-key handlers set held.up or held.down. During each animation frame, those inputs change state.gapY, and the draw() function uses state.gapY to place the opening. Collision detection compares the bird position to the opening.

AI code decision: I chose a moving gap instead of moving entire pipes sideways, because the player can immediately see how the new rule affects success or failure. This is a proposed design choice; describe any changes you personally decide to make.
