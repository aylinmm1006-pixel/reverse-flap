ONE CHANGE TO EXPLAIN:
Earlier newPipe() reset gapY to H/2. This made the opening snap to center between pipes. I removed that reset so the player keeps control of the opening's position. Test by moving the gap high, passing a pipe, and observing the next pipe.

ONE CODE RULE TO EXPLAIN:
In frame(), when the pipe overlaps the bird, the code checks whether the bird is outside the safe gap. If so, gameOver() runs. When the whole pipe passes safely, the score increases. There is no automatic win at five points; the game continues until a collision.
